# Tempo - Time Investment App

Tempo treats time as a currency. Track your "Invested" vs "Spent" time to maximize your daily ROI.

## 📱 Features

- **Ledger View**: Daily calendar showing your time transactions.
- **Manual Entry**: Quick-add modal for logging activities.
- **Invested vs Spent**: Categorize time to see where your day goes.
- **Local Storage**: Data persists on device using Hive NoSQL.

## 🛠️ Tech Stack

- **Flutter**: UI Framework
- **Riverpod**: State Management
- **Hive**: Local Database
- **GoRouter**: Navigation
- **Lucide Icons**: Iconography

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

2. **Generate Code** (if models change):
   ```bash
   dart run build_runner build
   ```

3. **Run App**:
   ```bash
   flutter run
   ```
